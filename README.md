# Ticlio – Dashboard de Proyecto

Sitio estático (HTML/CSS/JS puro, sin build).

- `index.html` – el dashboard
- `recursos/` – archivos descargables (cada uno pesa menos de 25 MB, para poder subirlos desde la web de GitHub)

## Publicar
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.
- **Vercel:** importar el repo, Framework Preset "Other", sin build command.

> El botón "Insumos" descarga 7 zips. Si el navegador pregunta, permitir descargas múltiples.
